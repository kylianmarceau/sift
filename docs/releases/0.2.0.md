# Sift 0.2.0

Sift now includes an experimental native Rust window manager alongside its
launcher and file search. Window management is **off by default** and runs
inside Sift; AeroSpace does not need to be installed.

- Nested tiling and accordion layouts, floating windows, split/join, move/swap,
  resizing, fullscreen, named workspaces and monitor assignments.
- Search open windows with `win` and workspaces with `ws` in the launcher.
- Application/title rules, configurable binding modes, per-display gaps,
  optional callbacks, and optional mouse focus/drag/resize behavior.
- Per-app AX workers, coalesced geometry requests, no periodic idle polling,
  and recovery positions saved before windows are arranged.
- Homebrew installs the bundled `sift` CLI, including `sift wm` commands.

## Upgrade and enable

Quit the old Sift, then run:

```sh
brew update
brew upgrade --cask kylianmarceau/sift/sift
open /Applications/Sift.app
sift --version
```

The version should be `0.2.0`. Open the launcher with Option–Space, search
**Settings**, and find **Window Management**. Use **Grant Window Control…**
and allow **Sift** in System Settings → Privacy & Security → **Device Control
and Data Access** on macOS 27, or **Accessibility** on older macOS. Permission
for the separate Sift WM Check app does not apply to Sift. Return to Sift and
enable **Native Window Management**. Use one automatic tiling manager at a
time while testing.

Control–Option–H/J/K/L focuses left/down/up/right; add Shift to move.
Control–Option–1…9 switches workspace; add Shift to send a window there.
Control–Option–Tab switches back; Control–Option–F toggles Sift fullscreen;
Minus/Equal resizes; Slash/Comma changes tiling/accordion orientation.
The workspaces are Sift workspaces, separate from Mission Control Spaces.

```sh
sift wm status
sift wm list-windows
sift wm layout floating tiling
sift wm enable off  # pause and restore positions, retain control service
sift wm enable on
```

Turning the Settings toggle off stops the manager and its shortcuts and asks
the native workers to restore original positions. Native fullscreen/minimized
windows remain under macOS control. Mouse behavior and callbacks are opt-in
configuration; edit the actual configuration through **Edit Rules and
Shortcuts…** in Settings and run `sift wm reload-config` after saving.

## Validation and limits

261 workspace tests and workspace/all-targets Clippy pass. Native smoke checks
cover actual frames, activation/focus, cursor positioning, workspaces,
minimize/restore, stalled-app responsiveness, mouse-listener lifecycle, and
pause/resume/shutdown restoration.

In two paired off/on runs with a 100k-entry index and three fixture windows,
management-on panel-show medians were 3.71 / 7.07 ms, typing-to-frame medians
14.56 / 15.45 ms, footprint 43 / 43 MB, and hidden CPU time 0.00 / 0.00 seconds
over 30 seconds. Disabled runs were comparable. These small samples do not
guarantee zero overhead across applications or configurations.

Broader real-app, multi-display and physical mouse-gesture acceptance remains
open. Existing AeroSpace configurations, every CLI flag, and third-party
AeroSpace protocol clients are not drop-in compatible. This release uses
the private AX-to-window-ID bridge and has not changed SIP settings.

Apple Silicon, macOS 13+. **Ad-hoc signed, not notarized**, matching previous
releases. If macOS blocks the app, use System Settings → Privacy & Security →
**Open Anyway**. `SHA256SUMS` accompanies the zip and disk image.
