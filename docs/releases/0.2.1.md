# Sift 0.2.1

Window shortcuts now work independently of automatic tiling. Enabling **Window
Shortcuts and Controls** leaves windows where you put them. **Automatic Tiling**
is a separate opt-in, off by default—including existing configurations that do
not explicitly set `automatic_tiling = true`.

- Persistent targets identify windows by exact application bundle ID and optional
  title/app-name expressions. Bindings keep working after windows reopen and apps
  restart, without saving temporary native window IDs.
- A missing target launches its app when possible, then focuses the matching
  window. Repeated requests coalesce; binding sequences wait before acting.
- Manual snapping to halves/quarters, center, maximize/restore, directional
  movement, resizing and fullscreen act only on an explicitly selected window.
- Manual positions stay in place when controls pause, stop or Sift quits.
  Turning Automatic Tiling off restores its original positions and retains
  manual shortcuts. No periodic polling or automatic mouse behavior is enabled
  in manual mode.

## Upgrade

Quit Sift, then run:

```sh
brew update
brew upgrade --cask kylianmarceau/sift/sift
open /Applications/Sift.app
sift --version
```

Expect `sift 0.2.1`. Open Sift Settings → Window Management, enable **Window
Shortcuts and Controls**, and leave **Automatic Tiling off**. Window-control
permission belongs to the installed Sift app: Device Control and Data Access on
macOS 27, or Accessibility on older versions. The separate Sift WM Check grant
does not apply to Sift.

Use **Edit Rules and Shortcuts…** to merge this example into your configuration:

```toml
[window_manager]
enabled = true
automatic_tiling = false

[window_manager.targets.terminal]
app_id = "com.apple.Terminal"
# title = '(?i)project'  # optional window-title expression
launch = true

[window_manager.bindings.main]
ctrl-alt-t = ["focus --target terminal"]
ctrl-alt-left = ["snap left"]
ctrl-alt-right = ["snap right"]
ctrl-alt-up = ["snap maximize"]
ctrl-alt-down = ["snap restore"]
```

Do not duplicate existing TOML tables. A configured `main` table replaces the
default shortcuts. Save and run `sift wm reload-config`. To discover names and
titles, use `sift wm list-apps` and `sift wm list-windows`.

```sh
sift wm focus --target terminal
sift wm snap left --target terminal
```

The first command focuses or launches the target. For an existing window, the
second positions it without changing focus; launching an app can activate it
through macOS. If no title matches within eight
seconds after launching, Sift reports that in status; it cannot recreate a
particular document or browser tab. A title-only target cannot launch an app
without its bundle ID. Closing/minimizing a missing target never launches it.

## Validation and limits

271 workspace tests pass. Native checks cover persistent focus, window
closure/reopening, app relaunch, manual snapping, unchanged neighboring windows,
passive refresh, position preservation on shutdown, and loading the saved target
after restarting controls, alongside the existing automatic-mode smoke checks.

Two paired off/manual runs with a 100k-entry index and three fixture windows
showed comparable launcher responsiveness: manual typing-to-frame medians
4.50 / 4.12 ms, physical footprint 42 / 42 MB, and hidden CPU time 0.00 / 0.00
seconds over 30 seconds. Small samples do not guarantee zero overhead; see the
[measurements and limits](https://github.com/kylianmarceau/sift/blob/v0.2.1/BENCHMARKS.md).

This remains experimental and is not a complete AeroSpace-compatible replacement.
Existing AeroSpace configurations and third-party protocols are not drop-in
compatible. Broader app, monitor and physical-gesture testing remains open.

Apple Silicon, macOS 13+. Ad-hoc signed, not notarized; use **Open Anyway** in
Privacy & Security if macOS blocks it. ZIP, DMG and SHA256SUMS are attached.
