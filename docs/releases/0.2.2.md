# Sift 0.2.2

Includes the persistent shortcuts and independent manual window controls from
0.2.1, plus a recovery fix for upgrading after automatic tiling. An already-restored
journal entry is now cleared immediately, so old tiling positions cannot be
replayed after a native manual move and restart.

## Upgrade and use manual control

Quit Sift, then run:

```sh
brew update
brew upgrade --cask kylianmarceau/sift/sift
open /Applications/Sift.app
sift --version
```

Expect `sift 0.2.2`. Enable **Window Shortcuts and Controls** in Sift Settings →
Window Management and leave **Automatic Tiling off**. Grant permission to the
installed Sift app under Device Control and Data Access on macOS 27, or
Accessibility on older macOS. The Sift WM Check grant is separate.

Use **Edit Rules and Shortcuts…** to merge persistent targets into the actual
configuration. Do not duplicate existing TOML tables. Example:

```toml
[window_manager.targets.terminal]
app_id = "com.apple.Terminal"
# title = '(?i)project'  # optional window-title expression
launch = true

[window_manager.bindings.main]
ctrl-alt-t = ["focus --target terminal"]
ctrl-alt-left = ["snap left"]
ctrl-alt-right = ["snap right"]
ctrl-alt-up = ["snap maximize"]
ctrl-alt-down = ["snap restore"]
```

A configured main table defines all its bindings. Save and run
`sift wm reload-config`. The target resolves against current windows whenever
pressed, so it survives window recreation and app/Sift restarts. A missing app
launches when possible; Sift waits up to eight seconds for a matching window.
It cannot recreate a particular document or browser tab. Manual window positions
remain in place when controls stop.

271 workspace tests, warnings-denied Clippy, native focus/reopen/relaunch checks,
and the stale-journal/manual-restart regression check pass. Paired 0.2.1
measurements show comparable launcher responsiveness with manual controls on/off;
this patch changes recovery handling, not the steady-state observation/search
path. See [measurements and limits](https://github.com/kylianmarceau/sift/blob/v0.2.2/BENCHMARKS.md).

Experimental; full AeroSpace configuration/CLI/protocol parity and broader app,
monitor and physical-gesture compatibility remain open. Apple Silicon, macOS 13+.
Ad-hoc signed, not notarized: use **Open Anyway** in Privacy & Security if blocked.
