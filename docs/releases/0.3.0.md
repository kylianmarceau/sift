# Sift 0.3.0

Clipboard history now supports pinned entries, individual deletion, source-app
tracking and filters, ignored apps, loose-match search, content recognition and a
preview pane. Set a dedicated history shortcut in Settings › Clipboard History.

Ctrl-J/Ctrl-K now move down/up through results alongside the existing navigation
keys.

The optional Paste and Pop shortcut pastes the newest unpinned entry into the
frontmost app and advances to the previous entry. It requires Accessibility
permission. Pinned entries remain until unpinned and survive Clear History.

Thanks to [tevans2](https://github.com/tevans2) for the clipboard improvements
in [#2](https://github.com/kylianmarceau/sift/pull/2) and
[#3](https://github.com/kylianmarceau/sift/pull/3), and navigation keys in
[#1](https://github.com/kylianmarceau/sift/pull/1).

## Upgrade

Quit Sift, then run:

```sh
brew update
brew upgrade --cask kylianmarceau/sift/sift
open /Applications/Sift.app
sift --version
```

Expect `sift 0.3.0`. Clipboard history remains off by default; enable it in
Settings › Clipboard History. Existing window controls are included.

The state database is upgraded in place. A backup named
`state.db.schema-<old version>` is kept beside it; older versions cannot open the
upgraded database.

Apple Silicon, macOS 13+. Ad-hoc signed, not notarized: if macOS blocks the
download, use Open Anyway in System Settings › Privacy & Security.
